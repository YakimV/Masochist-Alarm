# Masochist Alarm

A DIY alarm clock built with an ESP32-C3 that makes it harder to turn off the alarm and go back to sleep.

When the alarm goes off, you must physically get out of bed and move away from the device to silence it. It uses Wi-Fi signal strength (RSSI) to estimate whether you've moved far enough away.

### Features
- Wi-Fi web interface for alarm configuration
- Deep sleep for low power consumption
- Buzzer melodies and vibration motor
- RSSI-based alarm dismissal
- Battery voltage monitoring
- Built-in music tracks
- Hidden Easter eggs, button combinations, and mini-games
- Crash diagnostics and watchdog timer

### Hardware
- ESP32-C3
- 18650 Li-ion battery
- Passive buzzer
- Vibration motor
- Two buttons

**Made to turn getting out of bed into a requirement, not an option.**
